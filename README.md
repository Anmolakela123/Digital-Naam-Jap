# MantraMala

Mobile-first GitHub Pages devotional naam-jap website.

## Features
- Tap based jap counter
- Hindi voice recognition where supported by browser
- 108 Rudraksha bead visual with magical fade-away effect on every count
- Radha, Ram, Shiv, Krishna, Hanuman and Ganesh real supplied images
- Session time, jap/minute and completed mala result
- Local browser history and dashboard
- PWA-ready

## GitHub Pages
Upload all files to a repository root and enable **Settings → Pages → Deploy from branch → main / root**.

Voice recognition is browser-dependent; Chrome/Edge on compatible devices generally provide the needed Speech Recognition API.
